# agent-bounties-sp1-safe-v1

This source pin derives from SP1 `v6.4.0` at
`f66b4bff51d0ccff51d152e0f7f66b2ffedf3529` and changes the outer
Fiat-Shamir transcript for Agent Bounties Open Competition V2 Beta2.

The patch backports injective scalar absorption, explicit partial-batch length
binding, full native digest absorption, and base-field-order squeeze limbs to
both the native challenger and recursion circuit. It includes regression vectors
for every attack class in `GHSA-vj64-rjf3-w3v7` / `CVE-2026-46654`.

GPU proving is outside this release boundary. Beta2 assets must be generated by
the CPU prover, reproduced by two isolated Linux builders, and bound to the
exact Git commit, circuit version, verifier bytecode, ELF, vkey, and proof
evidence. This fork is not a claim that upstream SP1 is generally patched.
